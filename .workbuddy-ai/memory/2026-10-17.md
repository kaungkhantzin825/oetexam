# 2026-10-17

## Codebase Onboarding — OET Radiographer
Read through the entire project to learn the architecture. Key findings:

- Laravel 10 + Inertia + Vue 3 SPA, ported from Node/Express
- OET exam prep platform for Myanmar radiography students (bilingual EN + Burmese)
- 4 OET sub-tests: Listening, Reading, Writing, Speaking (+ Full mock exams)
- Question types: MCQ, ShortAnswer, Writing (AI-marked), RolePlay (AI-marked)
- AI provider chain: Gemini (primary, vision-capable) → Mistral (text-only fallback) → heuristic
- Writing answers can be photographed (handwritten) → Gemini vision transcribes + marks in one call
- Shared wall-clock Budget prevents AI chain from exceeding PHP execution limit
- Marking service is shared between submit() and result() to ensure consistency
- Lessons have two tracks: Radiography (profession-specific) vs General (shared medical paper)
- Admin panel: full CRUD for exams, questions, students, tutorials + AI generation tools + AI log viewer
- Database: MariaDB via XAMPP, 8 tables + 1 leaderboard view
- Migrations are idempotent/guarded (hasColumn checks) for MariaDB 10.4 compatibility

## ExamPlayer.vue — Bug Fixes & UI Overhaul
- **Bug fix (submit broken):** `doSubmit()` was accessing `res.data.attempt_id` but the `http` wrapper already unwraps the axios response — the correct path is `result.data.attempt_id` (where `result` is the raw JSON body). Fixed to use `result?.data?.attempt_id ?? result?.attempt_id ?? props.attempt.id` for resilience.
- **Bug fix (save before submit):** Added `saveDirty({ silent: true })` call before the submit POST, so any unsaved answers are persisted before marking.
- **UI overhaul (all questions on one page):** Replaced the one-question-at-a-time navigation (`index` / `current` computed / prev-next buttons / side navigator grid) with a single scrollable page that renders ALL questions, grouped by `part`. Each question card gets its own `QuestionCard` with question-specific answer handlers (`setAnswer(q.id, ...)`, `setImage(q.id, ...)`, `toggleMark(q.id)`).
- Removed unused imports: `ChevronLeft`, `ChevronRight`, `Grid3x3`, and the mobile navigator modal.
- Progress bar now shows `answeredCount / total` instead of `(index+1) / total`.
- Added a sticky summary bar showing answered/flagged/unanswered counts.
- Vite build passes successfully.
